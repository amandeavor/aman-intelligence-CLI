# Support

## Getting Help

If you need assistance using `aman-cli`, managing skills, or configuring MCP integrations:

1. **Quick Start**: Read the [QUICK-START.md](QUICK-START.md) guide.
2. **Import Guides**: Check [docs/IMPORT-GUIDE.md](docs/IMPORT-GUIDE.md) for importing from Cursor, Claude Code, Antigravity, and other AI tools.
3. **Specifications**: Consult [docs/ASSET-SPEC.md](docs/ASSET-SPEC.md) and [docs/REGISTRY-SPEC.md](docs/REGISTRY-SPEC.md).
4. **Issue Tracker**: Search [existing issues](https://github.com/amandeavor/aman-cli/issues).
5. **New Issues**: Open an issue using our structured issue forms.
