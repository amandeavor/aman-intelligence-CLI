# Roadmap

## Current Focus (v0.1.x)
- [x] Canonical asset format support for Skills, Prompts, MCPs, Packs, and Stacks.
- [x] Local filesystem and GitHub-backed registry adapters.
- [x] Import wizard supporting Claude Code, Cursor, Codex, and local folders.
- [x] `aman doctor` diagnostic health suite.

## Upcoming (v0.2.x)
- [ ] **Automated Semantic Versioning**: Automated resolution of semver constraints in `aman install`.
- [ ] **Interactive Stack Builder**: Visual terminal flow to compose and test custom multi-skill stacks.
- [ ] **Registry Integrity Signatures**: Cryptographic signing and verification for published `.amanpack` archives.
- [ ] **Plugin Discovery Enhancements**: Broader automatic detection for newly emerging AI IDE configs.
