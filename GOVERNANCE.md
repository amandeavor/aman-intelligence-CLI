# Governance

## Project Roles

### Maintainers
Maintainers review pull requests, oversee the architecture, publish releases, and maintain asset specification compliance.

Current maintainer:
- **Aman Awasthi** ([@amandeavor](https://github.com/amandeavor))

### Contributors
Anyone submitting issues, testing new imports, authoring skills, fixing bugs, or improving documentation.

## Becoming a Maintainer

Maintainership is based on demonstrated commitment to quality, sound architectural judgment, and reliability:
- Deep familiarity with TypeScript, Node.js CLI patterns, and the Aman asset specification.
- Thoughtful issue triage and constructive review of community PRs.
- Active care for terminal UX and security considerations around file manipulation and execution.

Maintainership is established by consensus among active maintainers.

## Decision Process

- Bug fixes, new import adapters, and UI polish proceed through standard PR reviews.
- Breaking changes to lockfiles (`aman-lock.json`), registry adapters, or asset metadata schema must follow the formal specification process in `docs/specs/`.
